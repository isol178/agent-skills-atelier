# Sanitize Artifacts Skill

セッション中に生成した成果物(ドキュメント・コード・レポートなど)から、
プロンプト指示・会話履歴・実装上の制約・作成プロセスの痕跡を取り除き、
最初から意図してその形で作られたかのような、単体で完結する成果物に
仕上げ直すためのスキル。

## このスキルが解決する課題

反復的なプロンプトや修正指示、例示、制約条件を経て作られた成果物には、
以下のような「作成過程の漏れ」が残りやすい:

- 「ご指示の通り〜」「〜という制約のため」のような自己言及
- ユーザーが意図伝達のためだけに出した例が、そのまま本文に混入
- 複数回のフィードバックによる継ぎ接ぎ感
- 想定読者にとって不要な注釈・言い訳

このスキルは、会話内容を「そのまま成果物に書くべき情報」と
「成果物の設計に反映させるべきだが、表には出さない情報」に分類し、
後者を自然な文章・構成・語彙選択に変換することで、単一の一貫した
声で書かれた最終成果物に仕上げる。

## 使い方

ユーザーが成果物の点検・整理・クオリティチェックを依頼したときに発火する。
`SKILL.md` に判定基準(残すべき/書き換えるべき/削除すべきの3分類)と
チェックリスト、書き換え例が記載されている。
